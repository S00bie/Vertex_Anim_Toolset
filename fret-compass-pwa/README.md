# Fret Compass (PWA)

Static site: host this folder over HTTPS (GitHub Pages / Netlify / Cloudflare Pages).
Local test: `python3 -m http.server 8080` then open http://localhost:8080 (localhost counts as secure).

Install: Chrome/Edge → install icon in address bar. iPhone → Safari → Share → Add to Home Screen.
After editing any file, bump `VERSION` in `sw.js`.
`icons/icon-1024.png` is the App Store icon for the later Capacitor step.
